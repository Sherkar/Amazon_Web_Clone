# Amazon Clone Frontend

A simple Amazon homepage clone built using HTML and CSS to practice frontend development and improve frontend design skills.

## 🚀 Features
- Amazon-style navbar
- Search bar UI
- Product category sections
- Hero section banner
- Responsive layout basics
- Clean and modern UI design

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📚 What I Learned
While building this project, I learned and practiced:
- Flexbox layout
- CSS positioning
- Navbar creation
- UI structure design
- Image alignment
- Responsive webpage basics
- Real-world website cloning

## 🎯 Purpose of This Project
This project was built for:
- Frontend development practice
- Improving HTML and CSS skills
- Understanding real-world website layouts
- Strengthening UI design concepts
